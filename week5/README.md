# Week 5 — Object Detection with YOLOv26n

## Tasks Completed
1. **Dataset Preparation & Model Training** — Annotated video frames using Label Studio for 3 classes (person, bicycle, car), resized images to 384px using ffmpeg, and trained a YOLOv26n model achieving 70.5% mAP50.
2. **Model Inference & Video Output** — Ran detection on 404 test images and stitched annotated frames into a final MP4 video using OpenCV.

## Results
- Model: YOLOv26n
- mAP50: 70.5%
- Classes: person, bicycle, car
- Test images: 404 frames
